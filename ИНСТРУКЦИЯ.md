# Инструкция по настройке и запуску RAG-бота

## Настройка YandexGPT

### 1. Создайте каталог в Yandex Cloud
- https://cloud.yandex.ru/ → "Каталоги" → "Создать каталог"
- Имя: `rag-bot`
- Скопируйте **Folder ID** из URL или информации о каталоге

### 2. Создайте сервисный аккаунт
- "Сервисные аккаунты" → "Создать сервисный аккаунт"
- Имя: `rag-bot-service`

### 3. Назначьте роль через Access bindings каталога

**Важно:** Роль нужно назначать на уровне каталога, иначе YandexGPT не даст доступ (403 Forbidden).

1. Откройте ваш каталог `rag-bot` в Yandex Cloud
2. Нажмите на `...` рядом с названием каталога
3. Выберите **"Access bindings"** (или "Привязки доступа")
4. Нажмите **"Add binding"** (или "Добавить привязку")
5. В поле **"Subject"** (Субъект) выберите ваш сервисный аккаунт (`rag-bot-service`)
6. В поле **"Role"** (Роль) выберите: **`AI Language Models User`** (`ai.languageModels.user`)
   - ⚠️ Не перепутайте с `foundationModels` или `vision` — нужна именно `ai.languageModels.user`
7. Нажмите **"Save"** (Сохранить)
8. Проверьте, что появилась строка:
   - Subject: ваш сервисный аккаунт
   - Role: `ai.languageModels.user`

### 4. Создайте API ключ
- Сервисный аккаунт → "Ключи" → "Создать новый ключ"
- Выберите: **"Create API key"**
- Scope: **`yc.ai.languageModels.execute`**
- Скопируйте API ключ (показывается один раз)

### 5. Создайте файл .env
В корне проекта создайте файл `.env`:

```bash
LLM_PROVIDER=yandex
YANDEX_API_KEY=ваш_api_ключ
YANDEX_FOLDER_ID=ваш_folder_id
TELEGRAM_BOT_TOKEN=
```

## Запуск бота

### Консольный режим

```bash
cd /Users/nataliashalaeva/YandexPractikum/architecture-rag-bot && source .venv/bin/activate && python3 scripts/task4/run_rag_bot.py
```

Или если виртуальное окружение уже активировано:


После запуска введите вопросы:
- `Кто такой Xarn Velgor?`
- `Что такое Synth Flux?`
- `Где находится Desertia?`

Для выхода: `exit`

### Telegram-бот

#### 1. Получите токен бота

1. Откройте Telegram
2. Найдите бота **@BotFather**
3. Отправьте: `/start` или `/newbot`
4. Укажите имя бота (например: `Мой RAG Бот`)
5. Укажите username бота (должен заканчиваться на `bot`, например: `my_rag_bot`)
6. Скопируйте токен, который даст BotFather

#### 2. Добавьте токен в .env

Откройте файл `.env` и добавьте токен:

```bash
TELEGRAM_BOT_TOKEN=ваш_токен_здесь
```

#### 3. Запустите Telegram-бота

```bash
cd /Users/nataliashalaeva/YandexPractikum/architecture-rag-bot && source .venv/bin/activate && python3 scripts/task4/run_telegram_bot.py
```

Или если виртуальное окружение уже активировано:

```bash
cd /Users/nataliashalaeva/YandexPractikum/architecture-rag-bot && python3 scripts/task4/run_telegram_bot.py
```

Ожидаемый вывод:
```
Загрузка векторного хранилища...
Инициализация LLM провайдера...
RAG-бот готов к работе!
Telegram-бот запущен!
```

#### 4. Используйте бота в Telegram

1. Откройте Telegram
2. Найдите вашего бота (по username, который вы указали)
3. Отправьте `/start` или просто задайте вопрос
4. Бот ответит на основе базы знаний

**Примеры вопросов:**
- `Кто такой Xarn Velgor?`
- `Что такое Synth Flux?`
- `Где находится Desertia?`

**Для остановки бота:** Нажмите `Ctrl+C` в терминале

## Решение проблем

**"YANDEX_API_KEY не установлен"** → Проверьте файл `.env` в корне проекта

**"ModuleNotFoundError"** → Установите зависимости: `pip install -r config/requirements.txt`

**"Индекс не найден"** → Выполните задание 3 (создание векторного индекса)
