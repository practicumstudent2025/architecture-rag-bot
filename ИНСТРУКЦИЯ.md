# Инструкция по настройке и запуску RAG-бота

## Настройка YandexGPT

### 1. Создайте каталог в Yandex Cloud
- https://cloud.yandex.ru/ → "Каталоги" → "Создать каталог"
- Имя: `rag-bot`
- Скопируйте **Folder ID** из URL или информации о каталоге

### 2. Создайте сервисный аккаунт
- "Сервисные аккаунты" → "Создать сервисный аккаунт"
- Имя: `rag-bot-service`

### 3. Назначьте роль через Access bindings каталога
**Важно:** Роль нужно назначать на уровне каталога, иначе YandexGPT не даст доступ (403 Forbidden).

1. Откройте каталог `rag-bot` → `...` → **"Access bindings"**
2. **"Add binding"** → выберите сервисный аккаунт
3. Роль: **`AI Language Models User`** (`ai.languageModels.user`)
4. Сохраните

### 4. Создайте API ключ
- Сервисный аккаунт → "Ключи" → "Создать новый ключ"
- Выберите: **"Create API key"**
- Scope: **`yc.ai.languageModels.execute`**
- Скопируйте API ключ (показывается один раз)

### 5. Создайте файл .env
Скопируйте `.env.example` в `.env` и заполните значения:

```bash
cp .env.example .env
```

Отредактируйте `.env`:
```bash
LLM_PROVIDER=yandex
YANDEX_API_KEY=ваш_api_ключ
YANDEX_FOLDER_ID=ваш_folder_id
TELEGRAM_BOT_TOKEN=ваш_токен_или_оставьте_пустым
```

---

## Установка зависимостей

```bash
cd папка_с_приложением
source .venv/bin/activate
pip install -r config/requirements.txt
```

---

## Запуск бота

### Консольный режим

```bash
cd папка_с_приложением
source .venv/bin/activate
python3 scripts/task4/run_rag_bot.py
```

### Telegram-бот

1. Получите токен у @BotFather в Telegram
2. Добавьте токен в `.env`: `TELEGRAM_BOT_TOKEN=ваш_токен`
3. Запустите:

```bash
cd папка_с_приложением
source .venv/bin/activate
python3 scripts/task4/run_telegram_bot.py
```

---

## Решение проблем

**"YANDEX_API_KEY не установлен"** → Проверьте файл `.env` в корне проекта

**"ModuleNotFoundError"** → Установите зависимости: `pip install -r config/requirements.txt`

**"Индекс не найден"** → Выполните задание 3 (создание векторного индекса)

**"403 Forbidden"** → Проверьте, что роль `ai.languageModels.user` назначена через Access bindings каталога
