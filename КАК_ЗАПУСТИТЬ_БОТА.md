# Как запустить RAG-бота

## Предварительные требования

1. Установлены зависимости:
   ```bash
   pip install -r config/requirements.txt
   ```

2. Создан файл `.env` в корне проекта с настройками:
   - `YANDEX_API_KEY` — ваш API ключ из Yandex Cloud
   - `YANDEX_FOLDER_ID` — ваш Folder ID
   - `TELEGRAM_BOT_TOKEN` — токен Telegram-бота (опционально)

3. Создан векторный индекс (задание 3 выполнено):
   - Индекс должен находиться в `data/vector_index/`

---

## Запуск консольного бота

### Шаг 1: Активируйте виртуальное окружение (если используете)

```bash
source .venv/bin/activate
```

Или на Windows:
```bash
.venv\Scripts\activate
```

### Шаг 2: Запустите бота

```bash
python scripts/task4/run_rag_bot.py
```

### Шаг 3: Используйте бота

После запуска вы увидите:
```
================================================================================
RAG-БОТ: Консольный режим
================================================================================
Введите 'exit' или 'quit' для выхода

Загрузка векторного хранилища...
Инициализация LLM провайдера...
RAG-бот готов к работе!

Ваш вопрос: 
```

Теперь можете задавать вопросы, например:
- `Кто такой Xarn Velgor?`
- `Что такое Synth Flux?`
- `Где находится Desertia?`

Для выхода введите: `exit`, `quit` или `выход`

---

## Запуск Telegram-бота

### Шаг 1: Активируйте виртуальное окружение (если используете)

```bash
source .venv/bin/activate
```

### Шаг 2: Убедитесь, что в `.env` указан `TELEGRAM_BOT_TOKEN`

```bash
TELEGRAM_BOT_TOKEN=ваш_токен_здесь
```

### Шаг 3: Запустите Telegram-бота

```bash
python scripts/task4/run_telegram_bot.py
```

### Шаг 4: Используйте бота в Telegram

1. Откройте Telegram
2. Найдите вашего бота (по username, который вы указали при создании)
3. Отправьте `/start` или просто задайте вопрос

---

## Возможные ошибки и решения

### Ошибка: "YANDEX_API_KEY не установлен"

**Причина:** В файле `.env` не указан API ключ

**Решение:**
1. Откройте файл `.env` в корне проекта
2. Добавьте ваш API ключ после `YANDEX_API_KEY=`
3. Сохраните файл
4. Перезапустите бота

### Ошибка: "YANDEX_FOLDER_ID не установлен"

**Причина:** В файле `.env` не указан Folder ID

**Решение:**
1. Откройте файл `.env`
2. Добавьте ваш Folder ID после `YANDEX_FOLDER_ID=`
3. Сохраните файл
4. Перезапустите бота

### Ошибка: "ModuleNotFoundError: No module named 'rag_bot'"

**Причина:** Скрипт запущен не из корня проекта

**Решение:**
1. Убедитесь, что вы находитесь в корне проекта `architecture-rag-bot`
2. Запустите команду снова:
   ```bash
   cd /путь/к/architecture-rag-bot
   python scripts/task4/run_rag_bot.py
   ```

### Ошибка: "No such file or directory: 'data/vector_index'"

**Причина:** Векторный индекс не создан

**Решение:**
1. Выполните задание 3 — создание векторного индекса
2. Запустите скрипты из `scripts/task3/`:
   ```bash
   python scripts/task3/step1_load_documents.py
   python scripts/task3/step2_split_chunks.py
   python scripts/task3/step3_create_embeddings.py
   python scripts/task3/step4_create_index.py
   ```

### Ошибка: "Invalid API key" или ошибка доступа к YandexGPT

**Причина:** Неправильный API ключ или отсутствие прав

**Решение:**
1. Проверьте, что API ключ скопирован полностью (без пробелов)
2. Убедитесь, что сервисному аккаунту назначена роль `ai.languageModels.user`
3. Проверьте, что при создании ключа выбран scope `yc.ai.languageModels.execute`
4. Попробуйте создать новый API ключ

### Ошибка: "TELEGRAM_BOT_TOKEN не установлен" (для Telegram-бота)

**Причина:** В файле `.env` не указан токен Telegram-бота

**Решение:**
1. Получите токен у @BotFather в Telegram
2. Добавьте его в файл `.env` после `TELEGRAM_BOT_TOKEN=`
3. Сохраните файл
4. Перезапустите бота

## Проверка готовности к запуску

Перед запуском убедитесь:

- [ ] Установлены зависимости: `pip install -r config/requirements.txt`
- [ ] Создан файл `.env` в корне проекта
- [ ] В `.env` указан `YANDEX_API_KEY` (не пустой)
- [ ] В `.env` указан `YANDEX_FOLDER_ID` (не пустой)
- [ ] Создан векторный индекс в `data/vector_index/`
- [ ] Вы находитесь в корне проекта при запуске
