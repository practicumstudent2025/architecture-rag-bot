## Проверка перед запуском

Если бот не запускается, проверьте:

```bash
cd /Users/nataliashalaeva/YandexPractikum/architecture-rag-bot && ls -la .env
```

Должен показать файл `.env`. Если файла нет, создайте его по инструкции.
