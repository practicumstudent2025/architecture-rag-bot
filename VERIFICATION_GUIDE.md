# Руководство по проверке качества замены терминов

## Как проверить, что тексты не распознаются как Star Wars

### Метод 1: Автоматическая проверка замены терминов

Запустите скрипт `verify_replacement.py`:

```bash
python3 verify_replacement.py
```

**Что проверяет:**
- ✅ Все ли оригинальные термины Star Wars заменены
- ✅ Присутствуют ли замененные термины в текстах
- ✅ Читаемость и логичность текстов
- ✅ Статистику использования замененных терминов

**Результат:**
- Отчет в консоли с детальной статистикой
- JSON отчет в `knowledge_base/verification_report.json`

**Ожидаемый результат:**
```
✅ Все оригинальные термины успешно заменены!
✅ ОТЛИЧНО: База знаний готова к использованию!
```

### Метод 2: Тестирование с помощью LLM

Запустите скрипт `test_llm_recognition.py`:

```bash
python3 test_llm_recognition.py
```

**Что проверяет:**
- Распознает ли LLM тексты как относящиеся к Star Wars
- Определяет ли модель вселенную Star Wars
- Логичность и читаемость текстов

**Режимы работы:**
1. **Ручная проверка** - выводит образцы текстов для проверки человеком
2. **Тест с OpenAI API** - автоматическая проверка через GPT-3.5-turbo (требует API ключ)
3. **Оба варианта** - комбинированный подход

**Настройка OpenAI API:**
```bash
export OPENAI_API_KEY="your-api-key-here"
```

**Ожидаемый результат:**
```
✅ Модель не распознала текст как Star Wars
✅ ОТЛИЧНО: Ни один текст не распознан как Star Wars!
```

### Метод 3: Ручная проверка образцов

1. Откройте несколько случайных файлов из `knowledge_base/`:
   ```bash
   head -50 knowledge_base/Xarn_Velgor.txt
   head -50 knowledge_base/Void_Core.txt
   head -50 knowledge_base/Aether_Knights.txt
   ```

2. Проверьте:
   - ❌ Нет ли упоминаний "Darth Vader", "Star Wars", "Jedi", "Sith" и т.д.
   - ✅ Есть ли замененные термины: "Xarn Velgor", "Aether Knights", "Synth Flux"
   - ✅ Текст логичен и читаем
   - ✅ Сохраняется смысл и структура

### Метод 4: Поиск оригинальных терминов

Используйте grep для поиска оригинальных терминов:

```bash
# Проверка на наличие оригинальных терминов
grep -r "Darth Vader" knowledge_base/*.txt
grep -r "Star Wars" knowledge_base/*.txt
grep -r "Jedi" knowledge_base/*.txt
grep -r "Death Star" knowledge_base/*.txt
```

**Ожидаемый результат:** Ничего не найдено (пустой вывод)

### Метод 5: Проверка наличия замененных терминов

Используйте grep для проверки замененных терминов:

```bash
# Проверка на наличие замененных терминов
grep -r "Xarn Velgor" knowledge_base/*.txt | wc -l
grep -r "Aether Knights" knowledge_base/*.txt | wc -l
grep -r "Synth Flux" knowledge_base/*.txt | wc -l
grep -r "Void Core" knowledge_base/*.txt | wc -l
```

**Ожидаемый результат:** Найдено множество упоминаний

## Критерии успешной проверки

### ✅ Успешно, если:
1. **Нет оригинальных терминов**: `verify_replacement.py` показывает 0 файлов с оригинальными терминами
2. **Есть замененные термины**: Все или большинство файлов содержат замененные термины
3. **LLM не распознает**: `test_llm_recognition.py` показывает, что модель не определяет Star Wars
4. **Тексты читаемы**: Средняя длина предложения 10-35 слов
5. **Логичность**: Тексты сохраняют смысл и структуру

### ❌ Требует доработки, если:
1. Найдены оригинальные термины в файлах
2. LLM распознает тексты как Star Wars
3. Тексты нечитаемы или потеряли смысл
4. Замененные термины отсутствуют в большинстве файлов

## Примеры проверки

### Проверка одного файла:

```bash
# Проверка на оригинальные термины
grep -i "darth vader\|star wars\|jedi\|sith" knowledge_base/Xarn_Velgor.txt

# Проверка на замененные термины
grep -i "xarn velgor\|aether knights\|synth flux" knowledge_base/Xarn_Velgor.txt
```

### Статистика замен:

```bash
# Подсчет упоминаний замененных терминов
for term in "Xarn Velgor" "Aether Knights" "Synth Flux" "Void Core"; do
    echo "$term: $(grep -r "$term" knowledge_base/*.txt | wc -l) файлов"
done
```

## Рекомендации

1. **Регулярно запускайте проверку** после изменений в базе знаний
2. **Проверяйте несколько файлов** разных категорий (персонажи, технологии, локации)
3. **Используйте комбинацию методов** для более надежной проверки
4. **Сохраняйте отчеты** для отслеживания изменений

## Устранение проблем

### Если найдены оригинальные термины:

1. Проверьте `terms_map.json` - все ли термины включены
2. Запустите `replace_terms.py` заново
3. Проверьте, что замена работает корректно (регистр, множественное число)

### Если LLM распознает Star Wars:

1. Увеличьте количество замененных терминов
2. Проверьте, что заменены не только имена, но и описания
3. Убедитесь, что нет упоминаний оригинальных названий в скрытом виде

### Если тексты нечитаемы:

1. Проверьте, что замена не нарушила структуру предложений
2. Убедитесь, что замененные термины согласованы (падежи, числа)
3. Проверьте, что не потерялись важные части текста при очистке HTML
