# База знаний для RAG-бота

## Описание

Эта база знаний создана на основе вселенной **Star Wars**, но все ключевые термины были заменены на вымышленные названия, чтобы гарантировать, что LLM не сможет использовать знания из своего обучающего датасета и будет полагаться только на предоставленную базу знаний.

## Процесс создания

### 1. Выбор предметной области
Выбрана вселенная Star Wars (starwars.fandom.com) как хорошо известная модель, что позволит проверить, действительно ли RAG использует векторный индекс.

### 2. Скачивание страниц
Скачано **31 страница** по ключевым сущностям:
- Персонажи (11): Darth Vader, Luke Skywalker, Princess Leia, Han Solo, Obi-Wan Kenobi, Yoda, Emperor Palpatine, Anakin Skywalker, R2-D2, C-3PO, Chewbacca
- Организации (6): Jedi, Sith, Rebel Alliance, Galactic Empire, Clone Trooper, Stormtrooper
- Локации (7): Tatooine, Coruscant, Naboo, Endor, Hoth, Dagobah, Alderaan
- Технологии (7): Death Star, Millennium Falcon, Lightsaber, Blaster, X-wing, TIE Fighter, The Force

### 3. Очистка текстов
HTML страницы были очищены от разметки, извлечен основной текст. Каждый документ сохранен как отдельный `.txt` файл.

### 4. Замена терминов
Все ключевые термины заменены на вымышленные названия согласно словарю `terms_map.json`:

**Примеры замен:**
- "Darth Vader" → "Xarn Velgor"
- "Death Star" → "Void Core"
- "The Force" → "Synth Flux"
- "Jedi" → "Aether Knights"
- "Tatooine" → "Desertia"
- "Millennium Falcon" → "Stellar Runner"

Всего заменено **36 ключевых терминов** в категориях:
- Персонажи (11)
- Организации (6)
- Локации (7)
- Технологии (7)
- Концепции (5)

## Структура файлов

- `*.txt` - 31 документ с замененными терминами
- `terms_map.json` - словарь всех замен (исходный → вымышленный)

## Результат

Создана уникальная база знаний из **31 документа**, которую невозможно "угадать" по памяти модели. Все тексты остались логичными и читаемыми, но больше не распознаются как относящиеся к вселенной Star Wars.

## Использование

Эта база знаний будет использоваться для:
1. Создания векторного индекса
2. Тестирования RAG-пайплайна
3. Проверки, что модель действительно использует предоставленные документы, а не знания из обучающего датасета
