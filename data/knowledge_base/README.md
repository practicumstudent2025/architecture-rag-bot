# База знаний для RAG-бота

## Описание

База знаний создана на основе вселенной Star Wars, но все ключевые термины были заменены на вымышленные названия, чтобы гарантировать, что LLM не сможет использовать знания из своего обучающего датасета и будет полагаться только на предоставленную базу знаний.

## Процесс создания

1. Выбор предметной области: вселенная Star Wars (starwars.fandom.com)
2. Скачивание страниц: 31 страница по ключевым сущностям
3. Очистка текстов: HTML страницы очищены от разметки, извлечен основной текст
4. Замена терминов: все ключевые термины заменены на вымышленные названия согласно словарю `terms_map.json`

Примеры замен:
- "Darth Vader" → "Xarn Velgor"
- "Death Star" → "Void Core"
- "The Force" → "Synth Flux"
- "Jedi" → "Aether Knights"
- "Tatooine" → "Desertia"
- "Millennium Falcon" → "Stellar Runner"

Всего заменено 36 ключевых терминов.

## Структура файлов

- `*.txt` - 31 документ с замененными терминами
- `terms_map.json` - словарь всех замен (исходный → вымышленный)

## Результат

Создана уникальная база знаний из 31 документа, которую невозможно "угадать" по памяти модели. Все тексты остались логичными и читаемыми, но больше не распознаются как относящиеся к вселенной Star Wars.

## Использование

База знаний используется для:
1. Создания векторного индекса
2. Тестирования RAG-пайплайна
3. Проверки, что модель действительно использует предоставленные документы, а не знания из обучающего датасета
