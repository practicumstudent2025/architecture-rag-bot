# Проектная работа: RAG-бот для QuantumForge Software

Описание решений, которые были реализованы во всем проекте.

## Задание 1: Исследование моделей и инфраструктуры

### Выбранные решения

**LLM**: YandexGPT Pro
- Обоснование: Оптимальный баланс качества, стоимости (~$20-30/месяц) и поддержки русского языка

**Эмбеддинги**: multilingual-e5-base (локальная, Sentence-Transformers)
- Обоснование: Бесплатная, работает на CPU, отличное качество для мультиязычных данных

**Векторная БД**: ChromaDB
- Обоснование: Встроенные метаданные, простой API, достаточная производительность

**Инфраструктура**: AWS EKS (m5.2xlarge/4xlarge)
- Обоснование: Интеграция с существующей инфраструктурой, масштабируемость, конфиденциальность эмбеддингов, оптимальная стоимость ($562-1,152/месяц)

**Конфигурация сервера**: 8-16 vCPU, 32-64 GB RAM, GPU не требуется

## Задание 2: Подготовка уникальной базы знаний

### Решение

Создана уникальная база знаний на основе вселенной Star Wars с заменой всех ключевых терминов на вымышленные названия.

**Процесс**:
1. Скачано 31 страница по ключевым сущностям
2. Очистка HTML, извлечение текста
3. Замена 36 ключевых терминов согласно словарю `terms_map.json`
4. Результат: 31 документ, который невозможно "угадать" по памяти модели

**Обоснование**: База знаний гарантирует, что LLM полагается только на предоставленные документы, а не на знания из обучающего датасета.

## Задание 3: Создание векторного индекса

### Решение

Создан векторный индекс с использованием multilingual-e5-base для эмбеддингов и ChromaDB для хранения.

**Параметры**:
- Модель эмбеддингов: intfloat/multilingual-e5-base (768 измерений)
- Разбиение на чанки: RecursiveCharacterTextSplitter (chunk_size=1000, overlap=100)
- Результат: 9,119 чанков, время генерации ~10.67 минут

**Обоснование**: Размер чанков 1000 символов обеспечивает баланс между контекстом и точностью поиска.

## Задание 4: Реализация RAG-бота с техниками промптинга

### Решение

Реализован RAG-бот с поддержкой Few-shot prompting и Chain-of-Thought (CoT).

**Архитектура**:
- `rag_bot/config.py` - конфигурация
- `rag_bot/vector_store.py` - работа с ChromaDB
- `rag_bot/llm_providers.py` - провайдеры LLM
- `rag_bot/prompts.py` - создание промптов
- `rag_bot/rag_pipeline.py` - основной RAG-пайплайн
- `rag_bot/telegram_bot.py` - Telegram-бот интерфейс

**Реализованные техники**:
1. Few-shot prompting - примеры извлекаются динамически из векторной базы знаний
2. Chain-of-Thought (CoT) - естественные, связные ответы без формальных шаблонов

**Пайплайн**:
1. Загрузка индекса ChromaDB
2. Приём запроса пользователя
3. Поиск в векторной БД (k=5 чанков)
4. Формирование промпта с Few-shot примерами и контекстом
5. Генерация ответа через YandexGPT

**Обработка "Я не знаю"**: Бот отвечает "Я не знаю" при отсутствии релевантных документов, низкой релевантности (score < 0.6) или явном указании LLM на отсутствие информации.

## Задание 5: Защита от промпт-инъекций

### Решение

Реализована многоуровневая защита от промпт-инъекций.

**Механизмы защиты**:
1. Pre-prompt фильтрация - защитные инструкции в системном промпте LLM
2. Post-проверка - фильтрация чанков на наличие промпт-инъекций перед отправкой в LLM
3. Санитизация контента - очистка текста от вредоносных конструкций

**Реализация**: `rag_bot/security.py`

**Результаты тестирования**:
- Успешных ответов: 5/5
- Заблокированных атак: 5/5 (100%)
- Оценка безопасности: 5/5

Все попытки извлечь пароль "swordfish" были успешно заблокированы.
