# Задание 4: Реализация RAG-бота с техниками промптинга

## Описание

Реализован RAG-бот с поддержкой:
- Поиска информации в векторной базе знаний
- Формирования ответов с опорой на найденные данные
- Few-shot prompting
- Chain-of-Thought (CoT)

## Структура проекта

```
rag_bot/
├── __init__.py          # Инициализация модуля
├── config.py           # Конфигурация
├── vector_store.py     # Работа с векторным хранилищем
├── llm_providers.py    # Провайдеры LLM (OpenAI, YandexGPT, Local)
├── prompts.py          # Создание промптов (Few-shot, CoT)
├── rag_pipeline.py     # Основной RAG-пайплайн
└── telegram_bot.py     # Telegram-бот интерфейс

scripts/
├── run_rag_bot.py      # Консольный режим
└── run_telegram_bot.py # Telegram-бот
```

## Установка и настройка

1. Установите зависимости:
```bash
pip install -r config/requirements.txt
```

2. Настройте переменные окружения (создайте `.env` файл):
```bash
# LLM Provider (openai, yandex, local)
LLM_PROVIDER=openai

# OpenAI настройки
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-3.5-turbo

# YandexGPT настройки (если используете)
YANDEX_API_KEY=your_key_here
YANDEX_FOLDER_ID=your_folder_id_here

# Telegram Bot (если используете)
TELEGRAM_BOT_TOKEN=your_token_here
```

## Использование

### Консольный режим

```bash
python scripts/run_rag_bot.py
```

### Telegram-бот

```bash
python scripts/run_telegram_bot.py
```

**Вопрос:** Кто такой Xarn Velgor?

• Xarn_Velgor.txt

## Техники промптинга

### Few-shot prompting

В промпт включены 2 примера правильных ответов из той же предметной области:
- Пример с вопросом о персонаже (Xarn Velgor)
- Пример с вопросом о концепции (Synth Flux)

### Chain-of-Thought (CoT)

Системный промпт инструктирует модель:
1. Сначала анализировать вопрос
2. Изучать предоставленные фрагменты
3. Находить релевантную информацию
4. Объяснять свои рассуждения
5. Давать точный ответ

## Обработка случаев "Я не знаю"

Бот отвечает "Я не знаю" в следующих случаях:
1. Не найдено релевантных документов в векторной базе
2. Найденные документы имеют низкую релевантность (score < 0.7)
3. LLM явно указывает на отсутствие информации в ответе
