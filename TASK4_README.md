# Задание 4: Реализация RAG-бота с техниками промптинга

## Описание

RAG-бот с поддержкой поиска информации в векторной базе знаний, формирования ответов с опорой на найденные данные, Few-shot prompting и Chain-of-Thought (CoT).

## Структура

```
rag_bot/
├── config.py           # Конфигурация
├── vector_store.py     # Работа с векторным хранилищем
├── llm_providers.py    # Провайдеры LLM
├── prompts.py          # Создание промптов
├── rag_pipeline.py     # Основной RAG-пайплайн
└── telegram_bot.py     # Telegram-бот интерфейс

scripts/task4/
├── run_rag_bot.py      # Консольный режим
└── run_telegram_bot.py # Telegram-бот
```

## Установка

1. Установите зависимости: `pip install -r config/requirements.txt`
2. Настройте `.env` файл
3. Создайте векторный индекс (см. `TASK3_README.md`)

## Использование

Консольный режим:
```bash
python3 scripts/task4/run_rag_bot.py
```

Telegram-бот:
```bash
python3 scripts/task4/run_telegram_bot.py
```

## Техники промптинга

### Few-shot prompting

В промпт включены 2 примера правильных ответов из той же предметной области.

### Chain-of-Thought (CoT)

Системный промпт инструктирует модель давать естественные, связные ответы без формальных шаблонов.

## Обработка случаев "Я не знаю"

Бот отвечает "Я не знаю" в следующих случаях:
1. Не найдено релевантных документов в векторной базе
2. Найденные документы имеют низкую релевантность (score < 0.6)
3. LLM явно указывает на отсутствие информации в ответе
